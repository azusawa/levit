# エディターの使い方

Levit で作られたエディターで文章を書く方向けのガイドです。入力、書式、リスト、貼り付け、キーボード操作について説明します。AI アシスト、コメント、共同編集などの機能は、お使いのアプリが有効にしている場合にだけ表示されます。ショートカットの **Mod** は、Windows と Linux では Ctrl、Mac では ⌘（Cmd）を表します。

## 入力とブロック

文書はブロックが上から順に並んだものです。段落、見出し、引用、リスト、表、コード、画像、区切り線がそれぞれブロックになります。エディターが空のときは「入力するか「/」でコマンドを開きます...」という案内が表示されます。

- **Enter** で新しいブロックを始めます。見出し、引用、コードブロックで Enter を押すと、次のブロックは通常の段落になります。
- **Shift+Enter** で同じブロックの中で改行します。引用やコードブロックに複数行を書くときに使います。
- ブロックの先頭で **Backspace** を押すと、上のブロックとつながります。
- Mac では **Alt+Backspace**、それ以外では **Ctrl+Backspace** で単語ごとに削除します。Mac の **⌘+Backspace** は行の先頭まで削除します。
- **Mod+A** で文書全体を選択します。

### スラッシュメニュー

行頭かスペースの後で `/` を入力すると、ブロックのメニューが開きます。続けて入力すると候補が絞り込まれます（例：`/見出し` で見出しだけ）。上下の矢印キーで選んで Enter を押すか、項目をクリックします。Escape、ほかの場所のクリック、`/` の削除で閉じます。and/or のような単語の中やコードブロックの中の `/` は、ただの文字として入力されます。今いるブロックが選んだ種類に変わり、`/` とその後に入力した文字は消えます。

- **テキスト** — 通常の段落。
- **見出し1**、**見出し2**、**見出し3** — 大・中・小の見出し。
- **引用** — 引用文や出典。
- **コードブロック** — 等幅フォントで表示するコード。
- **箇条書きリスト** — 点で示すリスト。
- **番号付きリスト** — 順番に番号を付けるリスト。
- **ToDoリスト** — チェックボックス付きのタスク。
- **区切り線** — 段落の間の横線。
- **画像** — 画像をアップロードするか、Web アドレス（URL）で追加。
- **表** — 行と列の表。

アプリによっては、メニューの最後に独自の項目が加わります。

## Markdown ショートカット

Markdown に慣れている方は、空の行の先頭で次のように入力できます。スペース（または最後の文字）を入力した時点でブロックが変わります。

- `# ` — 見出し1。`## ` と `### ` で見出し2と3になり、`#` は6つまで使えます。
- `> ` — 引用。
- バッククォート3つ — コードブロック。
- `- ` または `* ` — 箇条書きリスト。
- `1. ` — 番号付きリスト。
- `[] ` または `[ ] ` — ToDoリスト。`[x] ` ならチェック済みの項目になります。`- ` の直後でも使えます。
- `---` — 区切り線。
- `| 名前 | 価格 |` のような表の 1 行を書いて **Enter** — そのセルを見出し行にした表になり、キャレットは下の空の行に移ります。

コードブロックの中ではショートカットは働かず、入力したとおりに残ります。

## 文字の書式

文字を選択すると、その上に小さなツールバー（バブルメニュー）が表示されます。ボタンは左から次のとおりです。

- **太字**、**斜体**、**下線**、**取り消し線**
- **ハイライト** — 蛍光ペンで塗ったように目立たせます。
- **コード** — 文中に短いコードを表示します。
- **リンク** — リンクを追加・編集します（下記参照）。
- **見出し1**、**見出し2** — その行全体を見出しにします。
- **引用** — その行全体を引用にします。
- **表に変換** — 選んだ行を 1 行ずつ表の行にします。セルはタブで分け、タブがなければカンマで分けます。`名前, 価格` は 2 つのセルになります。

選択した文字すべてにすでに付いている書式は、ボタンが押された状態で表示されます。もう一度押すと書式が外れます。見出しや引用を通常の文章に戻すには、`/` を入力して **テキスト** を選びます。

キーボードでも操作できます。何も選択していないときは、続けて入力する文字に適用されます。

- **Mod+B** — 太字
- **Mod+I** — 斜体
- **Mod+U** — 下線
- **Mod+Shift+X** — 取り消し線
- **Mod+Shift+H** — ハイライト

### リンク

文字を選択してバブルメニューの **リンク** を押すと、入力欄が表示されます。アドレスを入力するか貼り付けて Enter を押します。`https://` は省略できます。`example.com` は `https://example.com` になります。リンクを外すには、リンクを選択して **リンク** を押し、入力欄を空にして Enter を押します。Escape を押すと、何も変えずに閉じます。`javascript:` のように危険なおそれのあるアドレスは受け付けません。入力欄の枠が赤くなり、リンクは追加されません。

## リストとToDoリスト

リスト項目の末尾で Enter を押すと次の項目ができます。空の項目で Enter を押すか、項目の先頭で Backspace を押すとリストから抜け、文字は通常の段落として残ります。

- **Tab** で項目を1段下げ、上の項目の下に入れます。その下にある項目も一緒に動きます。
- **Shift+Tab** で1段上げます。
- 下げた空の項目では、Enter や Backspace でまず1段上がります。

番号付きリストの番号は自動で振られ、階層ごとに数えます。Tab がこのように動くのはリストの中だけです（表ではセルを移動します）。それ以外では、通常の Web ページと同じようにキーボードのフォーカスがエディターの外へ移ります。

ToDoリストでは、ボックスをクリックするか、項目の中にカーソルを置いて **Mod+Enter** を押すと、チェックを付けたり外したりできます。Enter で作った新しい項目は未チェックで始まります。

## 表

スラッシュメニューで **表** を選ぶと（`/table` または `/表`）、サイズを選ぶグリッドが 3 列 3 行で開きます。グリッドをマウスで指してクリックするか、矢印キーで選んで Enter を押します。Esc で閉じます。グリッドを使わずにすぐ入れるには、名前の後に列から順にサイズを書きます。`/表 4x3` は 4 列 3 行の表を入れます。最初の行は見出し行で、太字で表示されます。

`| 名前 | 価格 |` のように Markdown の表の 1 行を書いて Enter を押すか、`名前, 価格` のような行を選んでバブルメニューの **表に変換** を押しても作れます。

- セルをクリックして入力します。**Tab** で次のセル、**Shift+Tab** で前のセルへ移ります。最後のセルで **Tab** を押すと行が 1 つ増えます。
- **Enter** はセルの中で改行します。
- キャレットが表の中にあると、表の上に **表ツールバー** が出ます。上・下に行を追加、左・右に列を追加、行を削除、列を削除、見出し行のオン・オフ、表を削除のボタンがあり、ボタンにマウスを合わせると説明が出ます。キーボードでは **Alt+F10**（Mac は Option+F10）で移り、矢印キーで選び、Enter で押し、Esc でセルに戻ります。
- セルの中のショートカット: **Mod+Enter** で下に行を追加、**Mod+Alt+Enter** で右に列を追加、**Mod+Shift+Backspace** で行を削除、**Mod+Alt+Backspace** で列を削除します。
- 同じコマンドはスラッシュメニューにもあります。セルの中で `/` を押すと表のメニューが出ます。**上に行を追加**、**下に行を追加**、**左に列を追加**、**右に列を追加**、**行を削除**、**列を削除**、**見出し行**（見出し行のオン・オフ）、**表を削除** があります。
- セルの先頭で Backspace を押しても、セル同士はつながりません。複数のセルを選んで Backspace を押すと、中身だけが消えます。表ごと消すには **表を削除** を使うか、表の前後の文章も一緒に選んで消してください。
- エディターより広い表は横にスクロールします。
- Web ページ、スプレッドシート、Google ドキュメント、Markdown から貼り付けた表は、表のまま入ります。

## コード、画像、区切り線

### コードブロック

スラッシュメニューの **コードブロック** を選ぶか、空の行の先頭でバッククォートを3つ入力するとコードブロックになります。コードの中で改行するには Shift+Enter を押します。Enter を押すとコードブロックから出ます。コードブロックに貼り付けると、コピーした内容がそのままプレーンテキストとして入ります。

言語を設定するには、ブロック右上のラベルをクリックします。言語を設定するまでは **プレーンテキスト** と表示され、ブロックにマウスを重ねると見えます。`js` や `python` などの名前を入力します。アプリが対応していれば、その言語に合わせてコードに色が付きます。入力欄を空にすると言語の設定が消えます。キーボードでは、コードブロックの中で **Alt+F10**（Mac では Option+F10）を押してラベルに移動し、Enter を押します。

### 画像

スラッシュメニューで **画像** を選びます。アプリが画像のアップロードに対応していればファイル選択画面が開き、複数の画像をまとめて選べます。対応していない場合は、画像の URL を尋ねられます。

アップロードに対応したアプリでは、スクリーンショットなどの画像を貼り付けたり、画像ファイルをエディターにドラッグ＆ドロップしたりもできます。1枚ずつアップロードされ、順に挿入されます。対応していないアプリでは、貼り付けたりドロップしたりした画像ファイルは無視されます。

### 区切り線

スラッシュメニューで **区切り線** を選ぶか、空の行に `---` と入力します。

画像や区切り線を削除するには、すぐ後ろのブロックの先頭で Backspace を押すか、すぐ前のブロックの末尾で Delete を押します。

## コピー、貼り付け、ドラッグ

コピーや切り取りをしても、書式、リスト、リンクはそのまま保たれます。ほかのアプリや別の Levit エディターにもそのまま貼り付けられます。

貼り付けるときは、構造を生かしつつ不要なものを整理します。

- Web ページや Google ドキュメントからの文章は、見出し、リスト、表、太字、斜体、リンクなどの書式が保たれます。
- 複数行にわたる `# タイトル` や `- 項目` のような Markdown は、対応するブロックに変換されます。
- それ以外のプレーンテキストは、1行が1段落になります。
- スクリプトや危険なリンクなど、安全でない内容は取り除かれます。

ほかのアプリやウィンドウから文章をドラッグして、好きな位置にドロップできます。エディター内で文章をドラッグして移動することはまだできないので、切り取りと貼り付けを使ってください。

## 元に戻す・やり直し

- **Mod+Z** — 元に戻す
- **Mod+Shift+Z** または **Mod+Y** — やり直し

書式の変更、貼り付け、AI の回答も元に戻せます。

## AI による執筆支援

アプリが AI サービスにつながっている場合、3つのコマンドが追加されます。AI が書く文章は、届いたそばから見出し、リスト、太字などの書式付きで表示されます。

- **文章を整える** — 選択した文章を直して整えます。文章を選択し、バブルメニューの **文章を整える** ボタンを押すか、スラッシュメニューから選んで今の行全体を整えます。
- **続きを書く** — カーソルの位置から AI が続きを書きます。`/` を入力してスラッシュメニューから選びます。
- **要約** — 文書全体の短い要約を、今のブロックの下に新しいブロックとして書きます。`/` を入力してスラッシュメニューから選びます。

AI が書いている間は、入力がぶつからないよう文書がロックされます。**Escape** を押すと止まり、それまでに書かれた分は残ります。**Mod+Z** で AI の回答全体を一度に取り消せます。

### 提案の採用と却下

**文章を整える** は元の文章をすぐには上書きせず、提案として表示します。削除される語は赤い取り消し線で、新しい語は緑で示されます。回答が終わると、そのすぐ下に小さなツールバーが表示されます。

- **採用** または **Mod+Shift+Enter** — 新しい文章を残します。
- **却下** または **Mod+Shift+Backspace** — 元の文章に戻します。

どちらも、開いているすべての提案にまとめて適用されます。

## コメント

アプリがコメントに対応していれば、バブルメニューに 💬 **コメント** ボタンがあります。文字を選択して押すと、コメントが付きます。

コメントが付いた文字は、薄い背景色と下線で示されます。その中にカーソルを置くと色が濃くなり、アプリがコメントのスレッドを表示します（多くはサイドパネルです）。コメント本文の入力、返信、削除はエディターではなくアプリで行います。

コメントのすぐ後ろに続けて入力した文字は、コメントの範囲に含まれません。文字をコピーしても、コメントは一緒にコピーされません。

## 共同編集

アプリで複数の人が同じ文書を編集できる場合、ほかの人の作業の様子が見えます。それぞれのカーソルは名前付きの色の線で、選択している文字は同じ色の背景で表示されます。ほかの人の変更は入力に合わせて反映され、自分のカーソルはその場に留まります。

共同編集中の元に戻す・やり直しは自分の変更だけに働き、ほかの人の変更は取り消しません。

## キーボードとスクリーンリーダー

マウスを使わなくてもエディターを操作でき、スクリーンリーダーが編集エリア、スラッシュメニュー、ツールバーを読み上げます。

- スラッシュメニューでは上下の矢印キーで項目を移動し、選んでいる項目が読み上げられます。Enter で決定し、Escape で閉じます。
- 文字を選択して **Alt+F10**（Mac では Option+F10）を押すと、書式ツールバーに移動します。コードブロックの中では言語ラベルに移動し、Enter で言語を変え、Escape でコードに戻ります。
- ツールバーでは左右の矢印キーでボタンを移動し、Home と End で最初と最後のボタンに移ります。Enter か Space でボタンを押します。オンになっている書式はスクリーンリーダーが伝えます。
- **Escape** で文章に戻ります。
- リンクの入力欄では、Enter で適用し、Escape で取り消します。
- リストと表の外で Tab を押すとエディターから出るので、エディターに閉じ込められることはありません。表では最初のセルで Shift+Tab を押すと出られます。

## ショートカット一覧

- **Enter** — 新しいブロック
- **Shift+Enter** — 同じブロック内で改行
- **/** — スラッシュメニューを開く
- **Mod+B** — 太字
- **Mod+I** — 斜体
- **Mod+U** — 下線
- **Mod+Shift+X** — 取り消し線
- **Mod+Shift+H** — ハイライト
- **Tab** — リスト項目を1段下げる、表では次のセル
- **Shift+Tab** — リスト項目を1段上げる、表では前のセル
- **Mod+Enter** — ToDo のチェックを切り替える。表では下に行を追加
- **Mod+Alt+Enter** — 表で右に列を追加
- **Mod+Shift+Backspace** — 表で行を削除
- **Mod+Alt+Backspace** — 表で列を削除
- **Mod+Z** — 元に戻す
- **Mod+Shift+Z** または **Mod+Y** — やり直し
- **Mod+A** — すべて選択
- **Alt+F10** — 書式ツールバーへ移動（コードブロックでは言語ラベルへ）
- **Escape** — メニューを閉じる、ツールバーを出る、AI を止める
- **Mod+Shift+Enter** — AI の提案を採用
- **Mod+Shift+Backspace** — AI の提案を却下（提案があるときは表の行の削除より先に働く）
